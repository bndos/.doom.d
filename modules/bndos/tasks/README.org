#+title: bndos tasks

Parallel coding tasks: each task is a git worktree (worktrunk) whose agent is
a session in the [[https://github.com/smagnuso/hydra-acp][Hydra ACP]] daemon, reviewed in diff-review.  Emacs, leader
agents and =bin/bndos-task= are all clients of the same session.  Nothing
here commits, pushes, merges or deletes worktrees.

Needs =hydra-acp= and =wt= on =PATH=, and =~/.hydra-acp/config.json= mapping
agent ids to the ACP adapters agent-shell uses:

#+begin_src json
{"agents": {"claude-code": {"command": "claude-agent-acp"},
            "codex": {"command": "codex-acp"}}}
#+end_src

* Use

| Key         | Command                  |                                       |
|-------------+--------------------------+---------------------------------------|
| =SPC g w w= | =bndos/task-dashboard=   | tasks of the known projects           |
| =SPC g w s= | =bndos/task-select=      | open a task's review                  |
| =SPC g w n= | =bndos/task-start=       | new worktree and agent                |
| =SPC g w r= | =bndos/task-review-here= | review the worktree you're in         |
| =SPC g w a= | =bndos/task-agent-here=  | its agent-shell                       |
| =SPC g w i= | =bndos/task-adopt=       | adopt an earlier conversation         |
| =SPC g w b= | =bndos/task-set-parent=  | record the parent branch              |
| =SPC g w p= | =bndos/task-add-project= | add a repository                      |

A review is diff-review's, with the agent flow on =C-c C-<key>= in the
overview and under =C-c _= in files; =C-h m= lists them.  Line comments are
made in a file's diff view (=g==, =gC=).  =bin/bndos-task --help= covers the
command line.

* Data

| What                              | Where                                            |
|-----------------------------------+--------------------------------------------------|
| threads, viewed marks, scope      | =<common git dir>/review/<branch>.json=          |
| task records, briefs, agents      | =$XDG_STATE_HOME/bndos-tasks/=                   |
| parent, agent, session, ticket    | =git config branch.<branch>.bndos-*=             |
| sessions and transcripts          | Hydra's =~/.hydra-acp/=                          |

* Tests

=tests/tasks/run-tests.sh=: =emacs -Q --batch= against Doom's packages, with
temporary repositories and a stub agent behind a private Hydra daemon.
